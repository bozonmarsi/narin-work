# Карточка товара нового поколения: план и состояние (2026-10-28)

## Зачем
Сегодня карточка (попап по клику) живёт в Tilda: данные о цветке набираются руками в «характеристиках»
в формате `Výdrž → 6–7 dní # заметка # 2`, вид задан Zero-блоком из 75 элементов, «Doporučené produkty»
зашиты в него руками. Менять долго, ошибиться легко, дизайн не гибкий.
Цель: **данные о цветке хранятся у нас (Supabase), редактируются в менеджерском приложении, сайт читает их
одной быстрой функцией**; карточка рисуется нашим HTML/CSS; рекомендации умные.

пока не включена новая.

## Рекомендации: как считаются
Строка 1 «Ladí k tomu» (что собрать вместе), строка 2 «Dokončete kytici» (что нужно, чтобы она красиво стояла).

**Ladí k tomu** (`rank_pairs`): роль цветка (главный / наполнитель / зелень / акцент; к главному ставим
наполнитель и зелень), **гармония цветов** (таблица `color_harmony`, правится), контраст высоты, штраф за тот же вид,
**ваши пары** (`product_pairs`, самый сильный сигнал, есть и «никогда не предлагать»), **статистика заказов**
(`product_co_purchase`, работает от 2 совместных заказов, растёт с данными), небольшой плюс за популярность.
Функция возвращает кандидатов по ролям; **сайт сам доранжирует по наличию**.

**Dokončete kytici** (`get_product_card.finish`): инструмент по виду (секатор для роз, пионов, гортензий; ножницы для
мягких стеблей, как на странице atelier), низкая ваза + кенцзан для «низких» цветов (тюльпан, ранункулюс, гиацинт или высота «Nízké»),
открытка по тону (тёплая/холодная). Всё из таблицы `product_accessories`: **новая дизайнерская ваза = одна строка
с `kind='vase'`**, она сама появится в карточках.

**Доставка** (делает сайт при показе): если в заказе есть товар «под заказ», весь заказ едет по его (более поздней)
дате. Поэтому «под заказ» помечается подписью «продлит доставку до <даты>», а в списке идут первыми те, что приедут вместе.

## Данные: что нашёл и поправил
* 39 из 66 цветов были без цвета, 38 без типа, 52 без высоты (высоту допишете вы). Фильтры на главной видели лишь часть каталога.
* 34 из 151 заказа содержали старые названия (`Růže Bombastik`, `Pivoňka koralová`, `White peony`...): сопоставлены в `order_name_map`.
* Дубль «Karafiát bílý spray» (без цены и без ссылки в Tilda) архивируется.
* В базе у `Pivoňka bílá` указан срок жизни 60 дней (`default_vase_life_days`): явная ошибка, проверьте.
* Не найдены в Tilda/без цены: `Magnolie`, `Nerine`, `Růže Haley`, `Růže novia`, `Růže mama (spray)`, `SET EDEN`, `SET Kremr`, `SET saracin`. Ничего с ними не делал.
* Цвета из словаря сайта: Bílá, Růžová, Červená, Žlutá, Fialová, Modrá. Я добавил **Zelená** (моллюцелла, эвкалипт, зелёная хризантема, Karafiat Kiwi): чип «Zelená» появится в фильтре главной, когда его добавят в `COLORS` в `tilda/pages/catalog-filter.html`; пока зелёные просто не имеют чипа.
* Нет в каталоге: **высокой вазы** (есть только низкая под кенцзан). Для высоких цветов блок «Dokončete» покажет инструмент и открытку. Дизайнерские вазы закроют этот пробел.

## Фотографии
Фото в каталоге студийные, портретные 2:3 (например 832×1248 и 1680×2455 px), белый фон, букет в стеклянной вазе.
Сейчас их режет квадрат. В новой карточке: показ целиком (`object-fit: contain`) на мягком фоне со скруглением,
зум по тапу, листание свайпом, миниатюры.
Скорость: CDN Tilda режет на лету, `.../-/resize/600x/<файл>` весит 47 КБ вместо 145 КБ, `-/resize/32x/` (1,7 КБ) для размытой заглушки.
Использовать `srcset` на 400/600/900 px и ленивую загрузку. Формат webp через параметр CDN не отдаёт (остаётся jpeg).

## Готовность к потоку клиентов
* Одна быстрая функция вместо скачивания страницы товара: карточка открывается мгновенно (можно кэшировать в браузере).
* Правила рекомендаций и инструмент/ваза лежат в таблицах (`flower_genus`, `color_harmony`, `product_accessories`), а не в коде.
* Статистика пересобирается функцией `refresh_product_co_purchase()`: **поставить в расписание ночью** (pg_cron), пока вручную после миграции вызвана один раз.
* Нужен журнал показов и кликов по рекомендациям, чтобы через месяц подкрутить веса (следующий шаг).
